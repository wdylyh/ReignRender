# ReignRender 模组 / ReignRender Mod

---

## 模组概述 / Mod Overview

**ReignRender** 是一个全面管理 Minecraft 渲染的模组。

**ReignRender** is a comprehensive mod for managing Minecraft rendering.

> 自 1.3 开发的面修改功能因为要重载资源，所以会自动重载。

> The Face Modification feature developed since 1.3 will automatically reload because it needs to reload resources.

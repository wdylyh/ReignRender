# ReignRender

一个全面管理 Minecraft 渲染的模组

---

## 兼容性

- **游戏版本**：Fabric 1.21.11  
- **前置模组**：malilib 0.27.16 或更高版本

---

## 当前功能

1. 禁止粒子渲染  
2. 禁止生物渲染  
3. 禁止方块渲染  

---

## 利用的机制

| 功能 | 对应拦截点 |
|------|------------|
| 粒子 | `renderParticles` |
| 实体 | `EntityRenderManager.render()` |
| 方块 | `renderBlockLayers`、`renderSection` |

---

## 性能提升

> 本模组在正常游玩情况下作用微乎其微，以下场景作用较大：

- 大量实体渲染（如动物农场、生物集群）  
- 过多粒子效果（如爆炸、药水云、火焰）  

> **注意**：本模组仅控制渲染，计算依然会进行（实体 AI、方块更新等不受影响）。
